# Комплект компонентов для стенда P1 (проект)

| Количество | Компонент | Назначение |
|---:|---|---|
| 2 | ESP32-S3 N16R8 DevKit | M1 CPU + Storage |
| +1 | ESP32-S3 N16R8 DevKit | M3 отдельный test-peer |
| +2 | ESP32-S3 N16R8 DevKit | M5–M7 Video, Audio/HID (дополнительные платы по мере развития) |
| 1–2 | паяные перфоплаты, штырьковые разъёмы | тестовая backplane/модули |
| по месту | CAT5e UTP (пары сигнал–земля) | общая магистраль |
| по месту | МГТФ + кембрики/стяжки | внутренний монтаж модулей |
| по месту | 74LVC138 / подходящий decoder и 74LVC125/245 | **выбрать только после утверждения логической схемы OE** |
| по месту | резисторы/подтяжки/конденсаторы | развязка и ограничения фронтов |
| 1 | SD microSD разъём и тестовая карта | Storage |
| 1 | PCM5102A или эквивалент I2S DAC | Audio |
| 1 | VGA DE-15 + резистивная лестница | Video |
| 1 | PS/2 разъём + согласование | HID |
| 1 | 5 В PSU с ограничением тока | стенд; мощность уточнить |
| 1 | логический анализатор + осциллограф | арбитраж, SPI, VGA, питание |

**Не покупать 8 одинаковых разъёмов по неподтверждённому pinout**. На M1 нужен простой прямой жгут, на M3 — интерфейсная схема для grant/OE, затем полноценная backplane.

## Предварительные вопросы к закупке

Сколько токов потребляет каждая плата под нагрузкой? Какой запас IO на каждой? Гарантирован ли Ioff у выбранного буфера? Нет ли 5V на контрольных контактах? Доступна ли схема выбранной N16R8 DevKit?

## Закупка под минимально полноценный ПК

После M0–M3 для итогового FULL PASS потребуются **пять одинаковых по семейству ESP32-S3 N16R8** (CPU, Storage, Video, Sound, Input); отдельная карта каждого типа. В ранней таблице строка «+2 Video, Audio/HID» описывала поэтапный стенд, но **для полностью собранной системы нужны три платы Video + Sound + Input поверх CPU + Storage**, не две. В варианте Input=USB предусмотреть USB OTG Host, VBUS 5 В и защиту питания; PS/2 требует уровень 3,3 В-safe. Вариант USB и PS/2 оба одновременно не требуется на первом этапе.
