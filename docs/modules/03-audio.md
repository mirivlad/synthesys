# Audio — автономный аудиосопроцессор

Audio — отдельная ESP32-S3 с собственными буферами, планировщиком воспроизведения и I2S-выходом (например, к PCM5102A + линейный аудиоразъём).

## Функции

- Одновременное проигрывание нескольких виртуальных голосов.
- PCM-сэмплы, огибающие ADSR, громкость, панорама, смешивание.
- Звуковые эффекты, музыкальные паттерны, трекерные композиции (в дальнейшем).
- Возможные синтезаторы AY/SID-подобного типа программно, **без обещания точной аппаратной эмуляции**.
- Локальный DMA/I2S, буферизация, контроль underrun; новые команды CPU — только смена событий, не передача каждого отсчёта.
- Пакетная загрузка музыки/сэмплов напрямую из Storage или иного совместимого модуля по гранту CPU.

## Пример API

```c
sample_t jump = audio_load_sample("/game/jump.wav");
audio_wait(jump);
audio_play(jump, 80 /* percent */);
audio_set_master_volume(70);
audio_stop(jump);
```

CPU владеет путями и FAT32; Audio получает handle ресурса и внутренний формат. Если ресурс не готов — возвращает `NOT_READY`, не читает неинициализированную память.

## Надёжность

Декодирование и микширование не должны зависать из-за очереди HESS. При длительной загрузке играть прежние буферы до корректной смены. Микшер защищён от переполнения/клиппинга; при отсутствие Audio CPU продолжает rescue-shell без звука.

## Проверки

Стендовый 440 Гц тон → I2S → DAC, проверка частоты, джиттера, пауз и шумов; затем 4+ голоса, HESS transfer под нагрузкой и полная перезагрузка во время звука.
