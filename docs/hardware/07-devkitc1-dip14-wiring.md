# CPU P0 — физические контакты ESP32-S3 DevKitC-1 и DIP-14 буфера

**Версия схемы:** инженерная ревизия 2026-11-17. **Целевая плата:** официальная Espressif **ESP32-S3-DevKitC-1 v1.1**, WROOM-1 N16R8, два ряда по 22 контакта. Это **не универсальная карта** для 38-контактных плат и клонов. При размещении антенной вверх и USB-разъёмами вниз J1 — левый ряд, J3 — правый. В каждой колонке номера от 1 сверху до 22 снизу. Реальную маркировку DevKit сравнивать с datasheet.

## 2. Правый ряд J3: отличие USB и резервных GPIO

На J3: позиции 2=GPIO43 TX0, 3=GPIO44 RX0; 19=GPIO20 USB D+, 20=GPIO19 USB D−; 1,21,22=GND. GPIO35, GPIO36, GPIO37 — позиции J3.13/J3.12/J3.11, но **недоступны для общих GPIO на N16R8 c Octal PSRAM**.

**USB Serial/JTAG к ПК подключается штатным кабелем к нижнему правому USB-порту платы** (при расположении антенной вверх). На DevKit D+/D− уже разведены. Не дублировать их проводами МГТФ на HESS.

## 3. U2 = SN74AHC125N, именно PDIP-14, выемка-ключ СВЕРХУ

> Взгляд на микросхему **сверху, со стороны маркировки**: слева сверху вниз 1…7, справа сверху вниз 14…8. При взгляде со стороны пайки нумерация зеркальная — не повторять этот рисунок с нижней стороны платы.

| Ножка U2 | Обозначение | Соединить |
|---:|---|---|
| 1 | /1OE | общее `CPU_GRANT_N` после interlock; 10 кОм pull-up к 3V3 |
| 2 | 1A | ESP J1.4 / GPIO4 / HESS_CLK |
| 3 | 1Y | HESS-40 pin9, через предусмотренный последовательный R при необходимости |
| 4 | /2OE | вместе с U2.1 и U2.10, по умолчанию HIGH |
| 5 | 2A | ESP J1.5 / GPIO5 / MOSI D0 |
| 6 | 2Y | HESS-40 pin11, опциональный последовательный R |
| 7 | GND | ESP J1.22 GND / общая шина GND |
| 8 | 3Y | HESS-40 pin19, XFER_OUT_N |
| 9 | 3A | ESP J1.15 / GPIO9, XFER_OUT_N |
| 10 | /3OE | вместе с U2.1 и U2.4, по умолчанию HIGH |
| 11 | 4Y | NC, четвёртый канал не используется |
| 12 | 4A | GND (фиксированный вход, не оставлять floating) |
| 13 | /4OE | 3V3 (четвёртый канал постоянно отключён) |
| 14 | VCC | 3V3 от ESP J1.1, C1=100 нФ рядом между ножками 14 и 7 |

**Замена:** раньше в документах упоминался **74LVC125**. Функционально можно применить SMD 74LVC125 с подходящим питанием, но TI SN74LVC125A **не имеет PDIP в актуальном перечне корпусов**. Для монтажа на перфоплате предпочтителен **SN74AHC125N** — доступный DIP-14, 3,3 В входит в допустимый диапазон питания. Не заменять на HCT125 без проверки гарантированной работы от 3,3 В.

## 4. Нельзя включать выходы буфера «просто GPIO13»

Для P0 соединить U2 pin1+4+10 в общий узел `/CPU_OE`, подтянуть к 3V3 резистором 10 кОм. **До реализации и электрической проверки backplane арбитра этот узел не соединять ни с GND, ни с управляющим GPIO**. U2 тогда физически Hi-Z, HESS по прошивке `BUS_ENABLE=0`.

Позже `/CPU_OE` может быть присоединён к проверенному аппаратному grant-декодеру CPU (проектный путь через HESS pin23), который запрещает master output при reset, owner != CPU и BUS_ENABLE=0. Никакого одновременного управления CLK другими процессорами.

## 5. Питание и первая проверка

1. Сравнить два ряда контактов реальной платы с таблицей Espressif, проверить маркировку N16R8, определить разъёмы USB.
2. На столе CPU питается **только от правого USB порта**, JP_PWR на шине разомкнут. HESS +5V нельзя подключать напрямую к USB VBUS.
3. U2 pin14=3V3, pin7=GND, проверка мультиметром до установки IC в DIP-панельку; C1 100 нФ у питания.
4. U2 pin1,4,10 высокие → выходы 3,6,8 Hi-Z; GPIO4/5/9 не могут возбуждать общую HESS без grant.
5. Программа CPU P0 USB monitor отвечает на `help`, `status`, `mem`, `key tap up`, но **не** инициирует HESS до interlock.
6. Проверить pin 1 по реальному keyed connector IDC и его datasheet до подачи +5 В.

Это инструкция по **расположению выводов и ограниченной сборке CPU P0**, а не конечная рабочая электрическая схема многомастерной HESS.
