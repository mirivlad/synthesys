# Backplane P1: размещение слотов и сигналы

**Статус: принципиальная архитектура, НЕ готовая монтажная схема.**

## Позиции

Один фиксированный CPU-контроллер (арбитр) и **до 8** одинаковых периферийных слотов. Нумерация: CPU = 0, слоты = 1…8. Логический `device_id` может отличаться от номера слота: у одной карты может быть несколько функций. Платы не должны зависеть от жёстко прошитого типа слота.

## Выбор владельца и адресата

- CPU задаёт `OWNER[3:0]` и `TARGET[3:0]` (0…8) на backplane.
- Логика выбора владельца формирует индивидуальный `GRANT_N[1..8]`; CPU одновременно закрывает собственный master path при OWNER != 0.
- Логика выбора адресата формирует индивидуальный `CS_N[0..8]` из TARGET, XFER_N, valid и признака OWNER != TARGET.
- Использовать дешифратор 4→16 или пару 3→8 (например, **74LVC138** с дополнительным старшим битом) и отдельные гейты enable; только **74LVC138** не даёт 9 независимых адресов CPU + восемь периферийных слотов.
- Инициализация без CPU: все master OE выключены, CS деактивированы, SYS_RST_N безопасен.
- Контакты `OWNER`/`TARGET` остаются на backplane; в слоте — **уже дешифрированные** `GRANT_N`, `CS_N`. На M1 достаточно двух изолированных тестовых узлов без всей логики дешифратора.

## Концептуальная карта универсального слота 2×16 IDC

Данный разъём — только **таблица функций** для обсуждения. Здесь ещё нет окончательных сторон, нумерации ножек, ключа и footprint. **По ней нельзя паять разъём.**

| Группа контактов | Линии |
|---|---|
| Питание | +5V × 2, GND × 2, дополнительные GND |
| Данные | CLK, D0, D1, D2, D3, рядом GND |
| Управление | SLOT_CS_N, SLOT_GRANT_N, XFER_OUT_N, ATTN_N, SYS_RST_N |
| Адрес | SLOT_ID0…2 (статическая кодировка, проверяется на старте) |
| Резерв | будущий READY/FAULT, расширения |

**XFER_OUT_N** подаётся в общую точку транзакции только с активного слота через физический gate; его **не** соединять напрямую в push-pull между картами. `GRANT_N` запрещает выходы при отсутствии владения. По умолчанию только CPU может выбрать другое устройство через управляющие линии; модуль не меняет TARGET самостоятельно.

## Проводка

Пассивная объединительная плата может использовать витые пары для межслотовых трасс SPI: **одна сигнальная жила и одна земля**. Если использовать отдельные многопарные кабели, согласовать общий путь тока и единый GND. Пары `CLK–GND`, `D0–GND`, `D1–GND`; `D2/D3` физически резервируются под QPI, `XFER–GND` отдельная пара. **Не** трактовать как LVDS/USB/CAN.

Монтажные МГТФ-провода внутри устройств соединяют разъём, ESP32-S3, buffers и локальные периферийные цепи. Короткие выводы ответвлений, нормальная механическая фиксация кабелей. Не устраивать звезду из длинных гибких проводов.

## Защита

На каждом модуле master-линии CLK, D0, XFER проходят через аппаратные разрешаемые выходные буферы; slave-линия D1 — через отдельный путь, разрешённый только при CS и transaction. Для QPI нужны отдельные разрешения и направления на D0..D3; это не то же самое, что 1-bit режим. Запрет двух master осуществляется **железом**, а не надеждой на прошивку.

Типовые IC для исследования: 74LVC138 (3→8), 74LVC245 (передатчик с OE, DIR), 74LVC125 (независимые буферы). **Ни один перечень IC не является готовой схемой**: нужно выбрать семейство с 3,3 В VCC, проверенными OE/IOFF, безопасным питанием и таймингами, затем нарисовать реальный schematic/netlist.

## Отличие от старого 20 pin

Исторические 20-контактные таблицы и ранние GPIO не подходят автоматически. Нужны отдельные /GRANT, /CS, gated XFER, физическая защита. Не совмещайте старый жгут v0 с новым.

## Пять модулей как обязательная нагрузка

**Функциональный минимум — CPU + Storage + Video + Sound + Input, все установлены одновременно.** Для предлагаемой конфигурации CPU + 8 периферийных слотов это означает четыре занятых периферийных слота и четыре резервных. Подтверждение электрической работы на 2–3 платах не подтверждает допустимые фронты, fanout и отсутствие коллизий при пяти. Требуется обязательная проверка на физической сборке с пятью активными ESP32-S3, включая нагрузку на питание, USB/PS2 Input, Video scanout, Sound I2S и прямые передачи Storage↔Video/Sound.

Зафиксировать как исходный проект именно перфоплаты и витые пары межслотовой магистрали с МГТФ внутри плат; переход на PCB не условие принятия проекта. [Метрики](../acceptance-five-modules.md).
