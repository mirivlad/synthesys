### Философия

«Синтезис» — это модульный домашний компьютер, созданный не ради производительности, а ради прозрачности, управляемости и инженерного удовольствия. Система вдохновлена духом ретро-ПК (Commodore 64, Amiga, ZX Spectrum), но построена на современной элементной базе с открытым исходным кодом.

«Не скрывать сложность — возвращать её под контроль пользователя».

### Общая архитектура

#### Топология

- Централизованная master–slave архитектура.

- CPU-модуль — единственный мастер на шине.

- Все периферийные модули (VGA, Audio, HID, Storage) — интеллектуальные слейвы.

- Прямое взаимодействие между слейвами запрещено — все операции инициируются CPU.

#### Базовая конфигурация


| Модуль  | Роль                               | Процессор      |
| ------- | ---------------------------------- | -------------- |
| CPU     | Центральный процессор, BIOS, Shell | ESP32-S3 N16R8 |
| Storage | Централизованное хранилище         | ESP32-S3 N16R8 |
| VGA     | Видеовывод, локальная VRAM         | ESP32-S3 N16R8 |
| HID     | Клавиатура (позже — мышь/джойстик) | ESP32-S3 N16R8 |
| Audio   | Аудиовывод, микширование           | ESP32-S3 N16R8 |


### Шина HESS-QPI

#### Назначение

**HESS** (Hardware Expandable SubSystem) — командная системная шина, объединяющая модули.

#### Физический уровень

Основан на **Quad SPI (QPI).**

Линии: HESS_CLK, HESS_IO[0:3], HESS_CSx, HESS_IRQx, HESS_RST.

Поддержка до **8 модулей**.

#### Протокол обмена

Базовый пакет (CPU → слейв):

```
[0xAA][DestID][CMD][ARG...][CRC8][0x55]
```

Ответ (слейв → CPU):

```
[0xAA][SrcID][STATUS][DATA...][CRC8][0x55]
```

#### Арбитраж шины

**CPU — единственный инициатор.**

Слейвы отвечают немедленно (ACK), затем работают асинхронно.


### Роль CPU-модуля

- Инициализация HESS-QPI.

- Чтение /boot.ini с Storage.

- Загрузка shell.elf.

- Отправка команд вида: «VGA, загрузи данные из Storage напрямую в VRAM».

**CPU не участвует в передаче данных между модулями.**

### Storage-модуль

**Чисто блочное устройство** (аналог HDD).

Поддерживает только:

READ_BLOCKS(lba, count), WRITE_BLOCKS(...).

Подключает SD-карту через SDMMC.

**Не содержит ФС** — всё обрабатывает CPU.

### Периферийные модули

Имеют **собственную PSRAM.**

Выполняют **автономную загрузку из Storage по команде CPU.**

Пример команды:

LOAD_FROM_STORAGE(storage_id, lba, len, local_addr)

### Поток данных (пример)

```
CPU → VGA: LOAD_FROM_STORAGE(lba=1024, len=64K, vram=0x2000)

VGA → CPU: ACK

VGA Storage: чтение блоков напрямую

VGA → CPU: IRQ (готово)
```
CPU не видит данные — только команды и статусы.

### Схемы подключения

#### Общая топология
```

			   +-------------------+

			   |    CPU Module     |

			   +---------+---------+

					     |

		+-----------------+-----------------+

        |                 |                 |

+-------v------+ +--------v-------+ +-------v------+

| VGA Module   | | Storage Module | | HID Module   |

+--------------+ +----------------+ +--------------+
```

#### HESS-QPI пины (пример)


| Сигнал      | ESP32-S3 GPIO |
| ----------- | ------------- |
| HESS_CLK    | 36            |
| HESS_IO0    | 35            |
| HESS_IO1    | 37            |
| HESS_IO2    | 33            |
| HESS_IO3    | 34            |
| HESS_CS_VGA | 16            |
| HESS_CS_STR | 17            |
| HESS_RST    | 2             |

#### Storage → SD-карта (SDMMC)


| ESP32-S3 | microSD |
| -------- | ------- |
| GPIO11   | CMD     |
| GPIO12   | D0      |
| GPIO13   | D1      |
| GPIO14   | D2      |
| GPIO15   | D3      |
| GPIO10   | CLK     |

#### VGA → Видео

I2S/LCD → DAC → VGA

Или: резистивная лестница → VGA (6-bit RGB)

#### HID → Клавиатура

PS/2 (CLK/DATA) или матрица 8×8

#### Audio → Звук

I2S → PCM5102A → 3.5 мм jack

#### Питание

5 В, 4 А общий блок

CPU генерирует HESS_RST

### Технические характеристики

| Параметр         | Значение             |
| ---------------- | -------------------- |
| Процессор        | ESP32-S3 N16R8       |
| PSRAM            | 8 МБ на модуль       |
| Шина HESS-QPI    | до 80 МГц (∼20 МБ/с) |
| Хранилище        | SD-карта до 1 ТБ     |
| Файловая система | FAT32 (на CPU)       |
| Формат программ  | ELF                  |

### Будущие расширения

- Wi-Fi-модуль (только для сети)

- NET-модуль (TCP/IP offload)

- RTC, вторая SD-карта, OTA

### Заключение

«Синтезис» — это **платформа для понимания.** Он сочетает:

- простоту ретро-ПК,

- гибкость модульной архитектуры,

- современные технологии.

Система остаётся полностью под контролем разработчика.
