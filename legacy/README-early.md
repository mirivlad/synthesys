# 🧠 Проект «Синтезис»  

### Modular Embedded Computer on ESP32-S3

  

> **«Не скрывать сложность — возвращать её под контроль пользователя»**

  

«Синтезис» — это **модульный домашний компьютер**, созданный на базе микроконтроллеров **ESP32-S3**.  

Система сочетает дух ретро-ПК (Commodore 64, Amiga) с современными технологиями: ELF-программы, QPI-шина, динамическая загрузка и открытая архитектура.

  

Цель проекта — не производительность, а **прозрачность, обучаемость и инженерное творчество**.

  

---

  

## 🌟 Особенности

  

- **Модульная архитектура**: CPU, VGA, Audio, HID, Storage — каждый на своём ESP32-S3.

- **Шина HESS-QPI**: высокоскоростная командная шина на основе Quad SPI (до 80 МГц).

- **Автономные модули**: VGA и Audio могут **напрямую загружать данные из Storage** без участия CPU.

- **Единое хранилище**: вся ОС, программы и ассеты — на одной SD-карте (через Storage-модуль).

- **Загрузка ELF-программ**: динамическое выполнение приложений без перепрошивки.

- **Ретро-совместимость**: текстовый режим 80×25, тайловая графика, трекерная музыка.

## 🏗️ Архитектура

  

```

                     +------------------+

                     |     CPU Module   | ← BIOS, Shell, ELF-loader

                     +--------+---------+

                              |

        +---------------------+---------------------+--------------------+

        |                     |                     |                    |

+-------v------+     +--------v-------+     +-------v------+     +-------v------+

| VGA Module   |     | Storage Module |     | HID Module   |     | Audio Module |

| (графика)    |     | (SD-карта)     |     | (клавиатура) |     | (звук)       |

+--------------+     +----------------+     +--------------+     +--------------+

  

```

  

- **CPU** — единственный мастер шины.

- Все модули общаются **только через команды**, без передачи сырых данных.

- Прямое взаимодействие между периферийными модулями **запрещено**.

  

---

  

## 📡 Шина HESS-QPI

  

- Физический уровень: **Quad SPI (4 линии данных + CLK + CS)**.

- Скорость: до **20 МБ/с**.

- Протокол: пакеты с CRC8, ACK/NACK, поддержка прерываний (`IRQ`).

- Поддержка до **8 модулей**.

  

Пример команды:

```c

VGA: LOAD_FROM_STORAGE(storage_id=0, lba=1024, len=65536, vram=0x2000)

```

→ VGA сам читает данные из Storage и кладёт их в свою VRAM.

## 📂 Структура системы

  

```

/boot.ini          # Конфигурация загрузки

/shell.elf         # Основная оболочка

/programs/*.elf    # Пользовательские приложения

/gfx/              # Спрайты, тайлы

/snd/              # Аудиофайлы

```

  

- Файловая система: **FAT32** (монтируется CPU).

- Все операции с файлами — через CPU.

- Storage — **чисто блочное устройство** (не знает о FAT32).

  

---

  

## 🛠️ Требования

  

- **ESP32-S3 N16R8** (16 МБ Flash + 8 МБ PSRAM) — для всех модулей.

- **microSD-карта** (UHS-I, Class 10) — в Storage-модуле.

- **Блок питания**: 5 В, 4 А (20 Вт).

- **Разъёмы**: для HESS-QPI (20+ пинов), VGA, PS/2, аудио.

## 🚀 Сборка и запуск

  

1. Соберите модули по схеме из документации.

2. Запишите `boot.ini` и `shell.elf` на SD-карту.

3. Вставьте карту в **Storage-модуль**.

4. Включите питание — система загрузится автоматически.

  

> Подробное руководство: [`docs/getting_started.md`](docs/getting_started.md)
